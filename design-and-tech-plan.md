# Codeling: design and tech plan (draft)

Browser app only. Nothing is built yet. Content lives in `learner-app-content-plan.md`. Mascot art lives in `mascot/`.

## 1. Product in one line
A Duolingo-style app that teaches programming. Runs entirely in the browser, offline after the first visit, no accounts, no backend. Light theme by default, dark mode toggle in Settings.

## 2. Look and feel (locked: "Brighter" palette)

| Role | Color | Used for |
|---|---|---|
| Main | Aqua-mint `#00E2C0`, edge `#00B39A`, tint `#D6FBF4` | Primary buttons, progress, completed lessons |
| Reward | Gold `#FFD000`, edge `#E0A800`, tint `#FFF1B3` | Current lesson, XP, rewards |
| Streak / warm accent | Coral `#FF5A4D` | Streak flame, gentle "not quite" cards |
| Info | Sky `#1EA7FF` | Hints, tips, glossary |
| Success | Leaf `#35DB5C`, edge `#1FAE40`, tint `#D9FBE2`, text `#0E6B27` | Correct-answer bar only, small accents |
| Background | Cream `#FFFBEF`, cards white, lines `#F5DFA0` | Whole app |
| Text | Ink `#073D33`, muted `#3E7A6D` | Never plain black |
| Locked | `#ECE6D3`, edge `#D2CAB0` | Locked lessons |
| Dark mode | bg `#10231F`, card `#183029`, line `#274840`, text `#E8F5EF`, teal `#34E0C4`, gold `#FFD04D` | Settings toggle |

- Unit banner colors cycle: aqua, gold, coral, sky, leaf, warm pink.
- Fonts: Nunito (headings and text), JetBrains Mono (code). Bundled with the app, not loaded from a CDN.
- Shape: big rounded corners, thick borders, chunky buttons with a thick bottom edge that presses down. Wrong answers use soft coral, never harsh red.
- Keep the leaf green to the correct-answer bar and small accents. It is loud in large areas.
- Mascot: hatchling blob in a plain cream eggshell (no braces), curly vine antennae with gold balls, 12 emotions. Colors match this palette. Stages planned: egg, hatchling, young, graduate.

## 3. Screens
1. **First-time setup:** goal, experience, daily goal, interests, then "Hatch your Codeling".
2. **Home (path):** left menu, center path with colored unit banners and winding lesson nodes, right panel with streak, XP, daily goal, review, Codeling growth.
3. **Lesson:** progress bar, mascot with the question, code block, tap options, Skip and Check. Correct gives a green bar with a short why. Wrong gives a coral bar with the explanation.
4. **Quiz:** lesson layout, different top bar color, no hints. Result unlocks the next unit (70% pass) or names lessons to review.
5. **Typed code challenge:** editor, Run, output panel, Check.
6. **Lesson complete:** confetti, mascot cheering, XP count-up, streak flame.
7. **Review:** short session from past mistakes.
8. **Profile:** streak calendar, XP, badges, mascot stage, courses.
9. **Settings:** dark mode, daily goal, change learning path, sound, backup and restore.

Phone-sized browser: left menu becomes a bottom bar, right panel moves below the path.

## 4. Tech plan

| Piece | What it is | Why |
|---|---|---|
| Svelte 5 + TypeScript | Builds the screens, typed JavaScript | Same as Valotrack, fast, small |
| Vite | Bundles and serves the app | Standard with Svelte |
| Lessons as JSON | Each unit is a data file of lessons and exercises | New courses need no new app code |
| Pyodide | Python compiled to run in the browser | Typed code challenges |
| Web Worker | Runs Python in the background | Page never freezes, timer kills runaway loops |
| CodeMirror 6 | Code editor with syntax colors | Much lighter than Monaco, themeable |
| IndexedDB | Browser storage for progress | Larger and safer than simple storage |
| PWA (service worker) | Installable, works offline | After first visit no internet needed |
| GitHub Pages | Free static hosting | Same as the Kitly hub |

### How the key parts work
- **Exercises:** the app reads a lesson file and renders each exercise type. One answer-checking module handles all types.
- **Typed challenges:** code runs in the worker with a time limit. Compare output to expected output, not the exact code. Pyodide loads only when the first typed challenge appears.
- **Step-through view:** Python records each line and the variables, and the app plays it back as a table. Works for small lesson programs.
- **Game logic:** XP, streak (learner's local date), daily goal, unit quizzes (70% to unlock, shuffled retries, test-out), simple spaced review of mistakes.
- **Saving:** progress in IndexedDB, settings stored separately. Export and Import backup, with a backup reminder. Ask the browser to protect the data from automatic cleanup.
- **Mascot:** each emotion is an SVG, generated by `mascot/build.mjs`. Later port to a Svelte component with an emotion prop.
- **Accessibility:** keyboard shortcuts (1 to 4 to choose, Enter to check), screen reader labels, respect reduced motion.
- **Input handling:** `input()` has no keyboard in a worker, so answers are fed in ahead of time.

### Risks
1. Pyodide is about 10 MB. Cached after the first load, but the first typed challenge pauses to load it.
2. GUI windows (tkinter) cannot run. The window-app course uses drawn previews and reading exercises.
3. Clearing browser data erases progress unless the learner backs up.
4. The step-through view is the least proven part and may need simplifying.
5. Service workers cannot be tested in the built-in browser pane. Test install and offline in Chrome.
6. Safari and iPhone can limit storage and Python size. Test there before claiming it works everywhere.
7. Files written by learner programs (Unit 14) go into Pyodide's pretend in-memory folder, which vanishes on page reload. The app must save that folder to browser storage (IndexedDB) and restore it, or the to-do list project will not remember between visits. Lessons tell learners the files live in a private pretend folder, not the real disk.
8. Not yet verified: current Svelte 5, Vite and Pyodide docs, Pyodide start speed, whether `input()` feeding and step-through work as planned.

## 5. Build phases
1. **Skeleton:** screen look, palette, fonts, mascot component.
2. **Lesson engine:** tap-based exercises, Units 1 and 2 in full.
3. **Game layer:** XP, streak, daily goal, celebrations, saving, backup. First point where a lesson can be tried.
4. **Typed code:** Pyodide, editor, Run, time limit.
5. **Quizzes and review:** unit gating, test-out, placement quiz, mistakes review.
6. **Polish and release:** installable offline version, web-app hardening pass, hosting.
